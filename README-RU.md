## Установка

### Windows
Вы можете скачать готовый бинарный файл со вкладки [Releases](https://github.com/AyuGram/AyuGramDesktop/releases).
### Linux
К сожалению, ~Gram пока что недоступен на каком-либо Линукс дистрибутиве.
### MacOS
К сожалению, ~Gram пока что недоступен на МакОС.
